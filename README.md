## ✨ System Features
- **Voucher Data Entry**: Form for voucher number, date, category/item, project, staff, transport mode, description, and amount.
- **Scanned Receipt Storage**: Attach scanned image (JPG/PNG) or PDF receipts for cash vouchers.
- **Accounts Cash Advance Control**: Track cash advances received from Accounts and real-time **Petty Cash Balance in Hand**.
- **Monthwise & Yearly Expenditure Analytics**: Category and project matrix tables.
- **Automated Excel Export**: Export structured Excel workbooks matching the IMS Petty Cash layout.
- **Day Mode & Dark Mode**: 1-click theme switcher.
- **GitHub Cloud Sync**: Backup and restore petty cash datasets across devices.
